Backend Coolify deployment is failing and I think we’ve identified the root cause.

Important clues from the Coolify logs:

* Docker build context shows: transferring context: 2B
* Deployment fails during Dockerfile COPY steps around lines 112–113.
* Error indicates COPY is trying to access paths like:
    * /workspace/artifacts/...
    * /workspace/tsconfig...
* Docker reports a failure while resolving those paths and exits with status 1.

This suggests either:

1. The Docker build context is effectively empty.
2. .dockerignore is excluding most of the repository.
3. Coolify is building from the wrong root directory.
